  There is now one choke point (`SyncNotificationService`) and thirteen call sites across notes,
  tasks, calendar, the AI task conversion and the push path, each firing after its transaction
  commits and none able to fail the request. `SyncModule` is `@Global()` for exactly this, pinned
  by `src/sync/sync.module.spec.ts`.
- **Not previously a row:** the WebSocket handshake verified a signature and nothing else. It now
  revalidates account status and session liveness the way `JwtStrategy` does, and fails closed
  when it cannot.
- **Not previously a row:** `/collaboration` kept shares in a process-local `Map` and accepted
  grants to unregistered addresses that resolved to nothing. It is Prisma-backed now, refuses an
  unknown recipient with `409`, and the duplicate rule is a database `@@unique`.
- **Not previously a row:** `JWT_ACCESS_EXPIRATION` / `JWT_REFRESH_EXPIRATION` appeared in
  `.env.example` and both Joi schemas while six separate literals in `src/auth` decided the real
  behaviour. One parsed value now backs the token `exp`, the response countdown, the session
  columns, the cookie `maxAge` and the module default.
- **Not previously a row:** Gemini sent its API key as a URL query parameter with no timeout.
  `src/ai/gemini.client.ts` puts it in the `x-goog-api-key` header, bounds the call with
  `AbortSignal.timeout`, caps the prompt, and keeps the key out of error text and logs.

**Found while doing the above, and fixed:**

- `docker-compose.prod.yml` passed `ENCRYPTION_KEY` to **no** service and `JWT_*_SECRET` to the
  worker but not… to neither variable it needed. `ConfigurationService`'s constructor and the
  worker's own Joi schema both require them, so `api` and both `worker` replicas exited during
  module init and `restart: unless-stopped` turned that into a crash loop. The prod stack could
  not have booted as committed. All three keys are now passed to both services.

**Still open, in the order someone should read them:**

1. **`prisma db push` has not been run.** `ResourceShare` exists in `prisma/schema.prisma` and in
   no database, so every `/collaboration` route fails until the schema is pushed against a

2. **Nothing reports whether `/sync` clustering is live.** Redis configured-but-unreachable falls

   same thing.
4. **A revoked session keeps its socket until it reconnects.** Handshake revalidation is not

5. **Two token lifetimes are still literals** — the MFA challenge (`"5m"`) and the passkey
   challenge TTL. Neither has an environment variable, and unlike the JWT pair above they are not
   advertised in any config surface, so this is a consistency gap rather than a lie.
6. **`BACKUP_ENABLED` / `BACKUP_SCHEDULE` have no caller** and there is no cron, timer or systemd
   unit in the repository. `scripts/backup-database.sh` is something an operator runs, not
   something the app runs; the getters should either drive a real scheduler or be deleted.
7. **CI has never run.** The first execution may well fail on a clean checkout for reasons the
   local gates cannot see.
